# Hi, I'm Dami

**Cloud & DevOps Engineer** working on AWS and Azure infrastructure, CI/CD pipelines and internal developer platforms.

I build infrastructure and delivery pipelines that let teams ship quickly without making reliability, security or operability someone else's problem.

## Selected projects

- **[pg-slot-sentinel](https://github.com/dhamsey3/pg-slot-sentinel)**: monitors Postgres replication slots and flags orphaned WAL retention before it fills RDS storage. Includes a docker-compose demo that reproduces the failure end to end.
- **[Internal Developer Platform API](https://github.com/dhamsey3/internal-developer-platform-api)**: a self-service API for provisioning cloud infrastructure and Kubernetes environments.
- **[PipelineForge](https://github.com/dhamsey3/pipelineforge-aws-devops-platform)**: an AWS-native delivery platform built with CodePipeline, CodeBuild, ECR and ECS Fargate.
- **[OpenStreetMap on AWS](https://github.com/dhamsey3/openstreetmap-aws-cloud-deployment)**: a production-style deployment using Terraform, ECS Fargate, RDS and CI/CD.
- **[Distributed Load Testing](https://github.com/dhamsey3/distributed-load-testing)**: distributed performance testing to see how systems behave under load.
- **[ELK SIEM Sandbox](https://github.com/dhamsey3/siem-sandbox-elk)**: a Docker lab for log analysis, detection engineering and security experiments.
- **[Automation with Python](https://github.com/dhamsey3/Automation-with-Python)**: small operational tools that remove repetitive work.

## How I work

- Infrastructure is code: reproducible, reviewed and easy to change.
- The safe path should also be the easiest one for developers.
- Monitoring and incident response are part of the design, not added after the first outage.
